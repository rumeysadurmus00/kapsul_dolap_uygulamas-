# Kapsül Gardırop ve Kombin Uygulaması

Bu proje, modern web geliştirme ve yapay zeka araçları kullanılarak hazırlanmış, kullanıcıların gardıroplarını dijitalleştirmesini ve akıllı kombinler oluşturmasını sağlayan web tabanlı bir uygulamadır.

## Kullanılan Teknolojiler
* **Frontend:** React (Vite)
* **Stil / Arayüz:** Tailwind CSS
* **Veri Saklama:** LocalStorage (Tarayıcı tabanlı kalıcı veri)
* **Geliştirme Süreci:** Yapay Zeka Asistanı desteğiyle planlanmış ve kodlanmıştır.

## Proje Özellikleri
1. **Dolabım:** Kıyafetlerinizi kategori, renk ve stil bilgileriyle birlikte ekleyip silebilirsiniz.
2. **Kombin Sihirbazı:** Beğendiğiniz parçaları kilitleyerek rastgele ve uyumlu kombin önerileri üretebilirsiniz.
3. **Favorilerim:** Üretilen başarılı kombinleri isimlendirerek favorilerinize kaydedebilirsiniz.
